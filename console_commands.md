# Console Commands

Assumptions:
- The operator console coordinates actions but does not directly execute infrastructure changes.

Boundaries:
- Commands must remain lane-aware and Copilot-approved.

Integration notes:
- Suitable commands include inspect, validate, route, refresh, and summarize.

Suggested commands:
- governance.show
- governance.refresh
- agent.status
- crawl.progress
- file.open
- mesh.schedule
- diagnostics.run
