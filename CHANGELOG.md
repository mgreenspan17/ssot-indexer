# Changelog

## 1.0.0 - 2026-06-05

Initial release of SSOT Indexer.

- Added local, SSH, and rclone scanning
- Added BLAKE3 hashing and UUID7 identity generation
- Added MIME and policy-based file classification
- Added Postgres schema, ingestion, and batch tracking
- Added canonical storage and shortcut generation
- Added `z://<uuid7>` resolver
- Added CLI and FastAPI entrypoints
- Added SQL migrations, scripts, and basic tests
