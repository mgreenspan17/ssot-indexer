# Dashboard Design

Assumptions:
- The dashboard must be useful before live crawl data exists.

Boundaries:
- Placeholder data is allowed until Warp and the mesh publish live feeds.

Integration notes:
- The static dashboard should later bind to dashboard_api.py.

Required panels:
- Agent status
- Crawl progress
- File browser
- Governance version
- System health

Future additions:
- Agent activity view
- Compute mesh view
- Logs view
- Roadmap view
- Feature suggestion input box
